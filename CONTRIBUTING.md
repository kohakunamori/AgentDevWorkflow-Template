# Contributing

Use a GitHub Issue template to describe the problem and how to reproduce it. Keep changes focused and include tests. Follow [AGENTS.md](AGENTS.md) and [review policy](docs/REVIEW_POLICY.md).

AI-generated code is welcome as a proposal, but does not waive test evidence or security checks. Do not submit keys or proprietary assets. For security reports use GitHub's private vulnerability reporting or contact repository maintainers privately (do not post exploitable secrets in public Issues).

For a new template consumer, replace this policy with project-specific ownership, supported versions, and release procedure.
